# Workspace Guidelines & Rules

## 1. No Mixed Languages
- Never mix English and Bengali in the same label, title, button, or badge (e.g., DO NOT write "Shipping Methods (লোকেশন ভিত্তিক মেথড)").
- Use pure, clean English for the Admin UI interface elements, table headers, forms, and buttons.

## 2. No Emojis in UI
- Do not use emojis in UI headings, buttons, tabs, modal headers, or form labels (e.g., NO 🚚, 📦, ⚙️, 💰, etc.).

## 3. Custom Modern UI Aesthetics (No WordPress Look)
- The admin dashboard must NOT look like WordPress or WooCommerce.
- Do not use WordPress colors (`#1d2327`, `#2271b1`), WordPress icons, or WordPress menu styles.
- Use a sleek, modern SaaS interface design (inspired by Vercel / Linear / Stripe) with clean typography, refined cards, subtle borders, and harmonious dark/light mode themes.

## 4. No Technical Logic Explanations in UI Design
- Do not show technical formulas, code math, or internal logic descriptions in the UI layout (e.g., DO NOT write "Total Fee = Base Fee + Max(...)"). Keep UI labels clean, brief, and professional.
